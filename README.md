# Angular Guide - ანგულარის (არაოფიციალური) ქართული გზამკვლევი

[ეწვიეთ წიგნის ვებსაიტს](https://angular.tetradze.com)

ვებსაიტი არის სტატიკურად გენერირებული [11ty-ის დახმარებით](https://www.11ty.dev/).

## კონტრიბუცია

თუ გსურთ წიგნში რაიმე ხარვეზების ჩასწორება ან ახალი თავების დამატება, შეგიძლიათ
დაფორკოთ ეს რეპოზიტორია და გამოგზავნოთ pull request-ები. თქვენი სახელი
და ლინკი (სურვილისამებრ) დაამატეთ კონტრიბუტორების სიაში (`src/articles/misc/contributors.md`).

თითოეულ თავს გააჩნია თავისი ფოლდერი `src/articles`-ში, სადაც შესაძლებელია ფაილების ქვეთავებად განაწილება.
რათა ახალი სტატიები სარჩევში გამოჩნდეს, საჭიროა მისი სათანადო ფაილების მისამართების მითითება
`src/includes/partials/summary.md`-ში (`.html` დაბოლოებებით, `.md`-ს მაგივრად).

გაითვალისწინეთ, რომ პროექტი იყენებს [PNPM](https://pnpm.io/)-ს პაკეტების მენეჯმენტისთვის და არა NPM-ს.

## დიაგრამები

დიაგრამებისთვის ` ```mermaid ` ბლოკს ვიყენებთ. ის **ბილდის დროს** SVG-დ
ირენდერება (`util/mermaid.js`), ანუ mermaid-ის ბიბლიოთეკა ბრაუზერში არ
იტვირთება და დიაგრამები მუშაობს ჯავასკრიპტის გარეშეც და ბეჭდვისასაც.

თითოეული დიაგრამა ორჯერ ირენდერება — ბნელი და ნათელი თემისთვის — და
გვერდზე ორივე ვარიანტი ხვდება; შესაბამისს CSS აჩენს.

- **დიაგრამის კოდში `theme` ან `themeVariables` არ მიუთითოთ**
  (`%%{init: ...}%%`), თორემ ორივე ვარიანტი ერთნაირი გამოვა. ფერები
  `src/styles/tokens.css`-იდან მოდის ავტომატურად.
- დიაგრამა ტექსტის სვეტში ეტევა (40rem), ამიტომ განიერი დიაგრამა
  პატარავდება — მოკლე წარწერები ჯობია. სამ-ოთხ მონაწილეზე მეტი
  `sequenceDiagram`-ში ტექსტს კითხვადობას უკარგავს.
- დარენდერებული SVG-ები `.temp/mermaid/`-ში ქეშირდება. პირველი ბილდი
  Chromium-ს უშვებს (puppeteer), შემდეგები — არა.
- თუ დიაგრამის სინტაქსი მცდარია, ბილდი ჩავარდება და ფაილის სახელს
  დაგვისახელებს.
